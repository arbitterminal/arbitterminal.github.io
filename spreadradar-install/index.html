Покрокова інструкція з реєстрації в SpreadRadar

Інструкція: як зареєструватися в SpreadRadar і встановити скрипт для ArbitTerminal.

Щоб користуватися SpreadRadar разом з ArbitTerminal, потрібно:

1️⃣ Увійти в SpreadRadar через Telegram

2️⃣ Встановити розширення OrangeMonkey у Chrome

3️⃣ Встановити скрипт SpreadRadar Links

4️⃣ Перевірити роботу скрипта в ArbitTerminal

КРОК 1. Вхід у SpreadRadar

Відкрийте сайт:

spreadradar.net

Натисніть кнопку:

✅ Увійти через Telegram

У вікні Telegram введіть номер телефону, на який зареєстрований ваш Telegram-акаунт, і натисніть:

✅ Далі

КРОК 2. Підтвердження входу в Telegram

У Telegram прийде службове повідомлення з підтвердженням входу на spreadradar.net.

Натисніть:

✅ Підтвердити

Якщо ви не робили цей запит — натисніть «Відхилити».

КРОК 3. Скопіюйте посилання на скрипт

Після входу в SpreadRadar у верхній частині сторінки знайдіть кнопку завантаження скрипта:

SpreadRadar-Links.txt

Натисніть на неї правою кнопкою миші та виберіть:

✅ Copy link address

або

✅ Копіювати посилання

Посилання має вигляд:

https://spreadradar.net/assets/SpreadRadar-Links.txt

КРОК 4. Перейдіть у Chrome Web Store

У Chrome відкрийте меню у правому верхньому куті:

⋮

Далі перейдіть:

Extensions → Visit Chrome Web Store

КРОК 5. Знайдіть OrangeMonkey

У пошуку Chrome Web Store введіть:

OrangeMonkey

Виберіть розширення OrangeMonkey.

КРОК 6. Встановіть OrangeMonkey

На сторінці OrangeMonkey натисніть:

✅ Add to Chrome

Після цього підтвердіть встановлення:

✅ Add extension

КРОК 7. Увімкніть User Scripts

Після встановлення OrangeMonkey відкрийте сторінку налаштувань розширення.

Увімкніть:

✅ Developer mode

✅ Allow User Scripts

Це потрібно, щоб Chrome дозволив запуск користувацьких скриптів.

КРОК 8. Відкрийте OrangeMonkey

Натисніть іконку OrangeMonkey на верхній панелі браузера.

Потім натисніть іконку налаштувань:

⚙️

КРОК 9. Перейдіть у My scripts

У меню OrangeMonkey відкрийте розділ:

My scripts

Потім натисніть кнопку:

✅ Install from URL

КРОК 10. Вставте посилання на скрипт

У поле Input URL вставте посилання:

https://spreadradar.net/assets/SpreadRadar-Links.txt

Натисніть:

✅ OK

КРОК 11. Підтвердіть встановлення скрипта

Відкриється сторінка встановлення скрипта.

Натисніть:

✅ Confirm installation

КРОК 12. Перевірте, що скрипт встановлено

У списку My scripts має з’явитися скрипт:

SpreadRadar Links for AT

КРОК 13. Перевірка роботи в ArbitTerminal

Відкрийте ArbitTerminal:

arbitterminal.online

Натисніть іконку OrangeMonkey.

Має бути увімкнено:

✅ All scripts enabled

✅ ArbitTerminal: SpreadRadar Links

Після цього в ArbitTerminal має з’явитися зелена кнопка Order Size, наприклад:

300$

Доступні варіанти:

100$ / 200$ / 300$ / 400$ / 500$

Якщо нічого не змінилося — оновіть сторінку:

Ctrl + F5

Як перевірити, що все працює?

Наведіть курсор миші на тикер у картці сигналу ArbitTerminal.

Має з’явитися підказка SpreadRadar з live-даними:

✅ OPEN

✅ DEPTH: OK

✅ міні-графік спреду

Якщо підказка з’явилася — скрипт встановлено правильно.

⚠️ Якщо щось не працює

Перевірте:

  1. Чи увійшли ви в SpreadRadar через Telegram
  2. Чи встановлено OrangeMonkey
  3. Чи увімкнено Developer mode
  4. Чи увімкнено Allow User Scripts
  5. Чи встановлено скрипт ArbitTerminal: SpreadRadar Links
  6. Чи відкрито саме arbitterminal.online
  7. Чи оновили ви сторінку ArbitTerminal через F5

Якщо tooltip показує, що потрібен логін або доступ — відкрийте spreadradar.net, увійдіть через Telegram і перевірте, що доступ активний.
