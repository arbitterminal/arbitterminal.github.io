# Покрокова інструкція з реєстрації в SpreadRadar Інструкція: як зареєструватися в SpreadRadar і встановити скрипт для ArbitTerminal. Щоб користуватися SpreadRadar разом з ArbitTerminal, потрібно: 1️⃣ Увійти в SpreadRadar через Telegram 2️⃣ Встановити розширення OrangeMonkey у Chrome 3️⃣ Встановити скрипт SpreadRadar Links 4️⃣ Перевірити роботу скрипта в ArbitTerminal * * * ## КРОК 1. Вхід у SpreadRadar Відкрийте сайт: [spreadradar.net](https://spreadradar.net) Натисніть кнопку: ✅ Увійти через Telegram У вікні Telegram введіть номер телефону, на який зареєстрований ваш Telegram-акаунт, і натисніть: ✅ Далі ![Вхід у SpreadRadar через Telegram](img/1_Register.png) Скрін 1 * * * ## КРОК 2. Підтвердження входу в Telegram У Telegram прийде службове повідомлення з підтвердженням входу на spreadradar.net. Натисніть: ✅ Підтвердити Якщо ви не робили цей запит — натисніть «Відхилити». ![Підтвердження входу в Telegram](img/2_Telegram_confirmation.jpg) Скрін 2 * * * ## КРОК 3. Скопіюйте посилання на скрипт Після входу в SpreadRadar у верхній частині сторінки знайдіть кнопку завантаження скрипта: `SpreadRadar-Links.txt` Натисніть на неї правою кнопкою миші та виберіть: ✅ Copy link address або ✅ Копіювати посилання Посилання має вигляд: [https://spreadradar.net/assets/SpreadRadar-Links.txt](https://spreadradar.net/assets/SpreadRadar-Links.txt) ![Копіювання посилання на скрипт SpreadRadar Links](img/3_Copy_scripts_link.png) Скрін 3 * * * ## КРОК 4. Перейдіть у Chrome Web Store У Chrome відкрийте меню у правому верхньому куті: `⋮` Далі перейдіть: `Extensions → Visit Chrome Web Store` ![Перехід у Chrome Web Store](img/4_Install_Orange_monkey.png) Скрін 4 * * * ## КРОК 5. Знайдіть OrangeMonkey У пошуку Chrome Web Store введіть: `OrangeMonkey` Виберіть розширення OrangeMonkey. ![Пошук OrangeMonkey у Chrome Web Store](img/5_Install_Orange_monkey2.png) Скрін 5 * * * ## КРОК 6. Встановіть OrangeMonkey На сторінці OrangeMonkey натисніть: ✅ Add to Chrome ![Кнопка Add to Chrome для OrangeMonkey](img/6_Install_Orange_monkey3.png) Скрін 6 Після цього підтвердьте встановлення: ✅ Add extension ![Підтвердження встановлення OrangeMonkey](img/7_Install_Orange_monkey4.png) Скрін 7 * * * ## КРОК 7. Увімкніть User Scripts Після встановлення OrangeMonkey відкрийте сторінку налаштувань розширення. Увімкніть: ✅ Developer mode ✅ Allow User Scripts Це потрібно, щоб Chrome дозволив запуск користувацьких скриптів. ![Увімкнення Developer mode і Allow User Scripts](img/8_Dev_mode_user_scripts.png) Скрін 8 * * * ## КРОК 8. Відкрийте OrangeMonkey Натисніть іконку OrangeMonkey на верхній панелі браузера. Потім натисніть іконку налаштувань: `⚙️` ![Відкриття налаштувань OrangeMonkey](img/9_Install_user_scripts.png) Скрін 9 * * * ## КРОК 9. Перейдіть у My scripts У меню OrangeMonkey відкрийте розділ: `My scripts` Потім натисніть кнопку: ✅ Install from URL ![Розділ My scripts і кнопка Install from URL](img/10_Install_user_scripts2.png) Скрін 10 * * * ## КРОК 10. Вставте посилання на скрипт У поле Input URL вставте посилання: [https://spreadradar.net/assets/SpreadRadar-Links.txt](https://spreadradar.net/assets/SpreadRadar-Links.txt) Натисніть: ✅ OK ![Вставлення посилання на скрипт в OrangeMonkey](img/11_Install_user_scripts3.png) Скрін 11 * * * ## КРОК 11. Підтвердьте встановлення скрипта Відкриється сторінка встановлення скрипта. Натисніть: ✅ Confirm installation ![Підтвердження встановлення скрипта в OrangeMonkey](img/12_Install_user_scripts4.png) Скрін 12 * * * ## КРОК 12. Перевірте, що скрипт встановлено У списку My scripts має з’явитися скрипт: ArbitTerminal: SpreadRadar Links Версія: `v1.39.1-asterdex` ![Встановлений скрипт ArbitTerminal SpreadRadar Links](img/13_Installed_user_script.png) Скрін 13 * * * ## КРОК 13. Перевірка роботи в ArbitTerminal Відкрийте ArbitTerminal: [arbitterminal.online](https://www.arbitterminal.online/) Натисніть іконку OrangeMonkey. Має бути увімкнено: ✅ All scripts enabled ✅ ArbitTerminal: SpreadRadar Links Після цього в ArbitTerminal має з’явитися зелена кнопка Order Size, наприклад: 300$ Доступні варіанти: 100$ / 200$ / 300$ / 400$ / 500$ Якщо нічого не змінилося — оновіть сторінку: Ctrl + F5 ![Перевірка роботи скрипта в ArbitTerminal](img/14_Finish.png) Скрін 14 * * * ## Як перевірити, що все працює? Наведіть курсор миші на тікер у картці сигналу ArbitTerminal. Має з’явитися підказка SpreadRadar з live-даними: ✅ OPEN ✅ DEPTH: OK ✅ міні-графік спреду Якщо підказка з’явилася — скрипт встановлено правильно. * * * ## ⚠️ Якщо щось не працює Перевірте: 1. Чи ви увійшли в SpreadRadar через Telegram 2. Чи встановлений OrangeMonkey 3. Чи увімкнений Developer mode 4. Чи увімкнений Allow User Scripts 5. Чи встановлений скрипт ArbitTerminal: SpreadRadar Links 6. Чи відкритий саме arbitterminal.online 7. Чи оновили ви сторінку ArbitTerminal через F5 Якщо tooltip показує, що потрібен логін або доступ — відкрийте spreadradar.net, увійдіть через Telegram і перевірте, що доступ активний.
