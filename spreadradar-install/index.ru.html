Пошаговая инструкция по регистрации в SpreadRadar

Инструкция: как зарегистрироваться в SpreadRadar и установить скрипт для ArbitTerminal.

Чтобы пользоваться SpreadRadar вместе с ArbitTerminal, нужно:

1️⃣ Войти в SpreadRadar через Telegram

2️⃣ Установить расширение OrangeMonkey в Chrome

3️⃣ Установить скрипт SpreadRadar Links

4️⃣ Проверить работу скрипта в ArbitTerminal

ШАГ 1. Вход в SpreadRadar

Откройте сайт:

spreadradar.net

Нажмите кнопку:

✅ Войти через Telegram

В окне Telegram введите номер телефона, на который зарегистрирован ваш Telegram-аккаунт, и нажмите:

✅ Далее

ШАГ 2. Подтверждение входа в Telegram

В Telegram придёт служебное сообщение с подтверждением входа на spreadradar.net.

Нажмите:

✅ Подтвердить

Если вы не делали этот запрос — нажмите «Отклонить».

ШАГ 3. Скопируйте ссылку на скрипт

После входа в SpreadRadar в верхней части страницы найдите кнопку загрузки скрипта:

SpreadRadar-Links.txt

Нажмите по ней правой кнопкой мыши и выберите:

✅ Copy link address

или

✅ Копировать ссылку

Ссылка имеет вид:

https://spreadradar.net/assets/SpreadRadar-Links.txt

ШАГ 4. Перейдите в Chrome Web Store

В Chrome откройте меню в правом верхнем углу:

⋮

Далее перейдите:

Extensions → Visit Chrome Web Store

ШАГ 5. Найдите OrangeMonkey

В поиске Chrome Web Store введите:

OrangeMonkey

Выберите расширение OrangeMonkey.

ШАГ 6. Установите OrangeMonkey

На странице OrangeMonkey нажмите:

✅ Add to Chrome

После этого подтвердите установку:

✅ Add extension

ШАГ 7. Включите User Scripts

После установки OrangeMonkey откройте страницу настроек расширения.

Включите:

✅ Developer mode

✅ Allow User Scripts

Это нужно, чтобы Chrome разрешил запуск пользовательских скриптов.

ШАГ 8. Откройте OrangeMonkey

Нажмите иконку OrangeMonkey на верхней панели браузера.

Затем нажмите иконку настроек:

⚙️

ШАГ 9. Перейдите в My scripts

В меню OrangeMonkey откройте раздел:

My scripts

Затем нажмите кнопку:

✅ Install from URL

ШАГ 10. Вставьте ссылку на скрипт

В поле Input URL вставьте ссылку:

https://spreadradar.net/assets/SpreadRadar-Links.txt

Нажмите:

✅ OK

ШАГ 11. Подтвердите установку скрипта

Откроется страница установки скрипта.

Нажмите:

✅ Confirm installation

ШАГ 12. Проверьте, что скрипт установлен

В списке My scripts должен появиться скрипт:

SpreadRadar Links for AT

ШАГ 13. Проверка работы в ArbitTerminal

Откройте ArbitTerminal:

arbitterminal.online

Нажмите иконку OrangeMonkey.

Должно быть включено:

✅ All scripts enabled

✅ ArbitTerminal: SpreadRadar Links

После этого в ArbitTerminal должна появиться зелёная кнопка Order Size, например:

300$

Доступные варианты:

100$ / 200$ / 300$ / 400$ / 500$

Если ничего не изменилось — обновите страницу:

Ctrl + F5

Как проверить, что всё работает?

Наведите курсор мыши на тикер в карточке сигнала ArbitTerminal.

Должна появиться подсказка SpreadRadar с live-данными:

✅ OPEN

✅ DEPTH: OK

✅ мини-график спреда

Если подсказка появилась — скрипт установлен правильно.

⚠️ Если что-то не работает

Проверьте:

  1. Вошли ли вы в SpreadRadar через Telegram
  2. Установлен ли OrangeMonkey
  3. Включён ли Developer mode
  4. Включён ли Allow User Scripts
  5. Установлен ли скрипт ArbitTerminal: SpreadRadar Links
  6. Открыт ли именно arbitterminal.online
  7. Обновили ли вы страницу ArbitTerminal через F5

Если tooltip показывает, что нужен логин или доступ — откройте spreadradar.net, войдите через Telegram и проверьте, что доступ активен.
